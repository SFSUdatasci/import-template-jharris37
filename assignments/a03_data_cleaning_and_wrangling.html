Issue:The Chinook catch data are “character” class so let’s fix it using the function mutate().

Change column content using mutate()

# Converting Chinook catch values to numeric type
catch_clean <- catch_data %>%
    mutate(Chinook = as.numeric(Chinook))
# isolating the issue
i <- which(is.na(catch_clean$Chinook))
i
[1] 401
# problem row
catch_data[i,]
    Region Year Chinook Sockeye Coho Pink Chum
401    GSE 1955       I      66    0    0    1
# changing invalid character value into numerical
catch_clean <- catch_data %>%
    mutate(Chinook = if_else(condition = Chinook == "I", 
                             true = "1", 
                             false = Chinook),
           Chinook = as.numeric(Chinook))

##check

Summary statistics using group_by() and summarize()

Suppose we are now interested in getting the average catch per region. Analyses like this conform to what is known as the Split-Apply-Combine strategy. This strategy follows three steps:

  1. Split: Split the data into logical groups (e.g., region, species, etc.)

  2. Apply: Calculate some summary statistic on each group (e.g. mean catch by year, number of individuals per species)

  3. Combine: Combine the statistic calculated on each group back together into a single table

# implementing Split-Apply-Combine strategy
mean_region <- catch_long %>%
    group_by(Region) %>%
    summarize(mean_catch = mean(catch))

Now, all together!

catch_original <- read_csv("https://knb.ecoinformatics.org/knb/d1/mn/v2/object/df35b.302.1")

mean_region <- catch_original %>%
  select(-All, -notesRegCode) %>% 
  mutate(Chinook = if_else(Chinook == "I", "1", Chinook)) %>% 
  mutate(Chinook = as.numeric(Chinook)) %>% 
  pivot_longer(-c(Region, Year), 
               names_to = "species", 
               values_to = "catch") %>%
  mutate(catch = catch*1000) %>% 
  group_by(Region) %>% 
  summarize(mean_catch = mean(catch)) %>% 
  arrange(desc(mean_catch))

Analysis

To asses whether the data is tidy, I applied a series of transformations using several new functions from tidyverse. First, I selected our desired region’s columns then corrected an issue in the Chinook column where one value was a character rather than an expected numerical value. After this adjustment, I reshaped the dataset from a wide format to a long format. Next, I converted catch values from thousands of fish to individual fish before finally grouping them by region and calculating their mean catches.
